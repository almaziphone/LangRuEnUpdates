# LangRuEn 0.3.0 · сборка 32

- Автозамена реже меняет короткие слова, команды, имена, адреса и идентификаторы. Замена фразы учитывает словарные исключения.
- Перед заменой и отменой по Esc LangRuEn сверяет фрагмент перед курсором, если редактор предоставляет его через универсальный доступ. При несовпадении или активном выделении удаление пропускается.
- Приложение получает обновления из стабильного канала.

Поддерживается macOS 14 и новее. Откройте `LangRuEn.dmg`, перенесите приложение в «Программы» и при необходимости включите «Мониторинг ввода» и «Универсальный доступ». Сборка подписана ad-hoc без нотарификации Apple. [Инструкция по установке](https://github.com/almaziphone/LangRuEnUpdates#установка).

## English

- Layout correction is less likely to replace short words, commands, names, addresses, and identifiers. Phrase correction respects dictionary exceptions.
- Before a correction or Esc undo, LangRuEn checks the text before the caret when the editor exposes it through Accessibility. A mismatch or active selection prevents deletion.
- The app checks the stable update channel.

Requires macOS 14 or later. Open `LangRuEn.dmg`, move the app to Applications, then grant Input Monitoring and Accessibility if prompted. This build is ad-hoc signed and has no Apple notarization. [Installation instructions](https://github.com/almaziphone/LangRuEnUpdates#installation).
